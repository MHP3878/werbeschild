3. Werbeschild für Windows und Android

Werbeschild entscheidet auf deinem Gerät, welche Adressen gesperrt werden. Live-Protokoll, Statistik, Einstellungen und Eltern-PIN bleiben auf dem Gerät. Es gibt kein Konto und keine Nutzungsstatistik an uns.

Damit Seiten und Apps funktionieren, braucht jedes Gerät Adress-Auskünfte (DNS). Erlaubte Abfragen schickt Werbeschild verschlüsselt an den in den Einstellungen gewählten DNS-Dienst – AdGuard DNS oder Cloudflare (Familien- bzw. Sicherheitsfilter). Dieser Dienst sieht den angefragten Namen (z. B. „wikipedia.org“) und die IP-Adresse deines Anschlusses. Ohne Werbeschild ginge dieselbe Abfrage unverschlüsselt an deinen Internetanbieter.

  • Filterlisten: Werbeschild lädt öffentliche Sperrlisten von den Original-Quellen (GitHub, jsDelivr, AdGuard). Dabei wird nur die Liste abgerufen.
  • Updates (Windows): Werbeschild fragt bei GitHub nach einer neuen Version und lädt sie dort herunter.
  • Android ohne VPN: Schaltest du das VPN aus, kann Android über „Privates DNS“ den Dienst AdGuard DNS nutzen.
  • Browser-Erweiterung „Live-Sperre“: Sie fragt nur das Werbeschild-Programm auf demselben PC, ob eine Seite gesperrt ist. Nichts geht ins Internet, nichts wird gespeichert.
